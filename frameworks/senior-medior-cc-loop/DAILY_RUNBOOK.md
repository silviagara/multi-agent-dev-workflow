# Daily Runbook

## Duration: 45–90 minutes (repeatable)

### 1) Queue shaping (10 min)
- Pull open tickets
- Label as S / M / L
- Pick 5–10 for today

### 2) Execution cycles (30–70 min)
- Run tickets through 8 gates
- Keep human interruptions to approval points only
- Close S tickets first for throughput

### 3) Wrap-up (5–10 min)
- Report closed tickets
- Report in-progress tickets + blockers
- Queue next day candidates

## Daily status template

- Closed today: <count + IDs>
- In progress: <IDs>
- Blocked: <IDs + reason>
- Merge-ready awaiting human: <IDs>
- Suggested next batch: <IDs>
